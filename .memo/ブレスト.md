# Javaアプリ練習プロジェクト(ブレスト)

## 概要
ひょんなことから、Javaを使ったアプリ開発をしなくてはならなくなった。
そのため、それの練習として趣味でJavaアプリの開発をしようと思う。
それの内容をブレストするのがこのmdである。

## 採用言語
言語はJavaを使用する。
他人へ引継ぎをする可能性があるため、Rustなどのいかつい言語は使用できない(使いたかった...)。
アプリはAndroidにもiosにも対応できるようにしたい。
後述の目標を満たせるものであったら良い。

---
# 最終目標
最終的に作成するアプリの概要・条件などを示す。

## アプリ条件
- Javaを使ったアプリであること
- Androidで動作すること
- 余裕があったらiosでも動作すること
- RSSI情報や加速度・地磁気などのスマホ取得データを扱えること
- Wifiがオフ(オフライン)でも動作すること

## アプリ内容
- RSSI情報や加速度・地磁気データを扱える。
- それらの蓄積データを使ってデータの整理・計算ができる。
- 具体的には、RSSIや加速度・地磁気データを使った位置推定をする。

## アプリで、必須ではないがやるかもしれないこと
- 蓄積データの管理(DBかcsvかメモリか)
- オフラインのDB(SQLite)での処理
- エラーログなどがわかりやすいよう、開発用にslackなどへの通知機能を付ける
- csv/Excelとしての出力
- 過去データの管理(実験番号などで変更できる)

## 練習開発プロジェクトについて
Javaアプリ開発の練習として、以下のプロジェクト案からいくつかを抽出して開発を行おうと思う。
これらはすべて趣味でRustなどで作ろうとしていたが、Javaにしてもいいかなと思っていたものなので、作りたさに差はない。
余裕があったら全部作ってもよさそうである。

### 自作アレクサ
音声入力を用いたものである。
以下に設計書(簡易版)を示す。
```
# 自作アレクサ設計書(簡易版)

## 概要
音声入力/LLMのapi/ずんだもんの3要素を使った自作アレクサである。
"Ok アレクサ"などの音声キーワードを検出し、対話を開始する。
入力された音声を文字起こしし、LLMに返答をリクエスト、その内容を音声読み上げに読み上げさせる

## 開発について
これは、サーバ側との通信を使おうと思う。
アプリでもブラウザ(またはPCアプリ)の両方で使えるようにし、PCでもスマホでも実行できるようにする。
サーバ側はRust、フロントエンドがJavaという練習方法もいいかもしれない。

## 実行フロー
アプリ立ち上げ
↓
キーワード待機
↓
キーワード音声受取
↓
音声を文字お越し
↓ サーバ側へ送信
LLMに返答をリクエスト
↓ 返答をユーザ側へ送信
音声読み上げをさせる
↓
キーワード待機
```


### 物理対決
一定時間で最も加速度を動かした人が勝ち。
簡単なゲーム
以下に設計書(簡易版)を示す。
```
# 自作アレクサ設計書(簡易版)

## 概要
加速度やジャイロ機能などを使用。
オフラインで動作させる
一人プレイゲームとなり、勝敗などは人間がはで比較することで対決ゲームとする

## ゲーム案
### 総移動量対決
加速度やジャイロ機能などの、絶対値の移動距離を蓄積
その結果を出す。

### ピーク値対決
加速度やジャイロ機能などのピーク値を記憶。
最大ピークを結果として出す。

### 歩数対決
ある閾値を飛び越えた加速度の回数を検出
その回数を歩数？として結果を出す

```

```
## 概要

方向版と色版を作る

## ゲーム案
簡単に、フローを示すことで、ゲーム案とする。

### ゲームフロー

A「↑を選択」
B「今までの↑を押したのち、↓を選択」
A「↑↓ + →」
B「↑↓→ + ↑」
B「↑↓→↑ + ↓」
A「↑↑　ミスったためBの勝利」
```
