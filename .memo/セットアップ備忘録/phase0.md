## 開発ロードマップの全体像

```
[Phase 1] Kotlin単体ビルド (現在の状態)
    ↓
[Phase 2] Java + Kotlin混合ビルド (言語間の連携を理解)
    ↓
[Phase 3] Gradleを使ったビルド (ビルド自動化の標準ツール)
    ↓
[Phase 4] Android SDKを使ったapk作成 (スマートフォンアプリ化)

```

### Phase 2: Java + Kotlin混合ビルド

KotlinはJavaと100%互換性があるのが最大の強みです。

* **やること:** Javaで書いたクラスをKotlinから呼び出す（、またはその逆）プログラムを作成し、`javac` と `kotlinc` を両方使ってビルドします。
* **学ぶこと:** クラスパス（`-cp` オプション）の概念や、2つの言語がどうやって裏でつながっているかの基礎を学びます。

### Phase 3: Gradleを使ったビルド

プログラムが複数ファイルになり、JavaとKotlinが混ざると、手動でコマンドを打つのが不可能になってきます。そこで登場するのが**Gradle**です。

* **やること:** `build.gradle.kts` という設定ファイルを書き、`gradle build` というコマンド一発で、JavaとKotlinの混ざったコードを自動でコンパイル・依存関係（ライブラリ）の解決・JARの作成までできるようにします。
* **学ぶこと:** 現代のJava/Kotlin開発における「標準のビルドシステム」の動かし方をマスターします。

### Phase 4: Android SDKを使ったapk作成

いよいよ最終ゴールです。Androidアプリは、内部で100% Gradleを使ってビルドされています。

* **やること:** Phase 2で学んだGradleの設定に「Android用のプラグイン」を追加し、Android SDKを読み込ませて `.apk` を出力します。
* **学ぶこと:** スマホアプリ特有のビルドサイクル、デジタル署名（apkのサイン）、画面リソースのコンパイルなどを学びます。
